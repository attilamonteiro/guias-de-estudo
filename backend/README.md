# Guia de Backend

80 perguntas de entrevista de backend: as 30 originais mais as 50 de [roadmap.sh/questions/backend](https://roadmap.sh/questions/backend). Cada pergunta traz o método de aprendizado mais adequado (Feynman, 5 Porquês, Comparar, Passo a passo, Playbook, Ameaça→defesa, Primeiros princípios, System design), resposta em português e inglês, armadilhas e autoteste.

As 11 perguntas do roadmap.sh que repetem as originais reaproveitam a mesma explicação; o progresso conta 69 explicações distintas.

## Editar

| Arquivo | O quê |
| --- | --- |
| `src/q-a.js`, `q-b.js`, `q-c.js` | Perguntas 1–30 |
| `src/r-a.js`, `r-b.js`, `r-c.js` | Perguntas do roadmap.sh (R01–R50) |
| `src/app.js` | Interface, busca, treino, resumo, progresso |
| `src/index.html` | Estilos e estrutura |

`index.html` desta pasta é gerado: depois de editar, rode `node build.mjs` na raiz do repositório.

## Fonte

As explicações são originais; do roadmap.sh vêm apenas os enunciados das perguntas.
